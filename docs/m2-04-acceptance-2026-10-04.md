# M2-04 验收记录（2026-10-04）

## 实现结果

笔记详情新增 Markdown、Word、PDF 和打印预览。所有输出绑定明确的已确认 revision，
正文与出处从数据库读取，未保存修改不进入导出。新草稿提供打开正式版本的入口；历史
正式版本支持导出。草稿返回 409，跨用户或错误资产/版本配对返回 404，删除/清除课程
拒绝创建、读取、预览、重试及下载。

统一 Markdown 包含保存正文、逐条来源/综合改编/AI 补充标记、历史文件名、位置、引用
摘录和版本信息。原资料删除后仍保留出处，并在请求快照中记录删除说明。统一内容
SHA-256 与文件 SHA-256 分别记录，下载响应带 revision/hash 标识。旧通用笔记保留
原正文和版本级出处，不伪造逐条来源。

新增 008_note_exports.sql、export_jobs worker 和持久任务。任务创建时固定快照，
同一输入重复点击复用任务；租约过期可领取恢复，旧尝试无权发布新结果。失败清理临时
文件，丢失的缓存文件可重试。文件目录私有，每次下载重新授权，不暴露文件路径。

Word 使用 Pandoc 与 A4/中文字体模板；PDF 和打印使用同一 HTML/CSS，常见公式分别
为 OMML / MathML。转换禁止外部图片、链接访问及原始脚本执行。前端可恢复任务、重试、
下载中文文件名，并在同源隔离 iframe 中预览与打印。Docker、Compose 与 CI 增加
导出 worker、Chromium 和中文字体依赖。

## 启用与边界

启用时同步依赖、安装 Chromium、执行迁移，重启后端并启动 export_jobs worker，
更新前端；具体命令和配置见 [笔记导出](note-exports.md)。

第一版 Word/PDF/打印的外部图片转为替代文字，链接保留显示文字，原始 HTML/OpenXML
按文字处理；Markdown 保留原语法。不支持任意 LaTeX 宏，不保证不同格式分页完全一致。
私有文件可能在硬中断后留下不可访问的孤立文件；定时物理回收不属于本卡范围。
未进行真实打印机打印或模型质量评测；本功能不调用模型，也不重新判断正文的知识正确性。
