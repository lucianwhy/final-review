# M2-05 / M2-06 验收记录（2026-10-04）

本次按 `docs/backlog.md` 中两张卡的范围执行验收。使用独立临时 PostgreSQL 容器
`final-review-m2-acceptance`（本机 55436 端口），未修改业务数据库或已有课程。

## 验证范围

- M2-05：笔记请求、澄清、补充要求、草稿卡片和普通消息保存在同一时间线；刷新及页面、
  课程切换后从历史打开原会话，草稿链接不变，资产数量仍为一；应用和 Agent 重建后可继续
  待补充任务；重复提交和恢复不追加重复消息/资产；笔记任务更新最近活动顺序。
- M2-05 授权：使用真实数据库、注册和登录的两个账号，验证跨用户与跨课程读取历史、
  继续澄清、恢复及取消请求均返回 404；他人不能读取生成的草稿 revision。
- M2-06：未选资料时提交禁用；只使用显式选择的 ready 资料；同名短编号、失败资料禁用、
  全选、多选及五份上限；章节不匹配保留表单；取消清除 active_note、旧任务不可恢复，刷新
  不重开，普通聊天和重新发起笔记可用；桌面/手机自定义类型菜单与配置弹层截图检查通过。
- 真实模型：使用本机配置的 `qwen-plus`，在上述隔离数据库中复验请求澄清、应用重建、后台
  生成、草稿重开、恢复去重、取消及再次发起。材料为合成 TCP 讲义；普通聊天使用固定响应，
  embeddings 使用测试实现。本次验证工作流和持久化，不作为完整课程内容质量评测。
