# 试题配置弹窗手动测试

## 启动

如后端已经运行，请重启后端，使 `/api/chat/dispatch` 和取消接口更新生效。
在项目根目录启动后端：

```powershell
uv run uvicorn final_review.api:create_app --factory --host 127.0.0.1 --port 8080 --workers 1
```

前端在 `D:/final_review/final-review/frontend` 启动：

```powershell
npm run dev -- --host 127.0.0.1
```

使用终端显示的前端地址。选择一门已有可检索资料的课程，进入 AI 对话。
如需上传资料，保持资料处理 worker 运行。此流程不需要笔记 worker。
M3-02 已接入生成：升级前先执行 `uv run python -m final_review.migrations`，并在独立终端
运行 `uv run python -m final_review.quiz_jobs`。详细说明见 [试卷草稿生成](quiz-draft-generation.md)。

## 测试步骤与预期

1. 发送“模拟试卷一般如何设计？”。应正常讨论，不仅因为出现“模拟试卷”就打开弹窗。
2. 发送“请根据第三章课件生成一套模拟卷，8 道选择题、2 道简答题，基础难度，不限时，不纳入导入题，不允许 AI 补充”。
   应在模型完成意图识别后打开“补充试题要求”，预填明确的章节、数量、难度和开关。
3. 对比生成笔记弹窗：背景遮罩、标题、字体、边框、圆角、按钮和下拉菜单保持相同主题。
   打开难度菜单，测试鼠标选择、上下方向键、Enter；Escape 先关闭菜单，再按一次取消配置。
4. 参数未全时，“确认试题配置”禁用。将题量总和改到 37，按钮应禁用；限时必须填写 1～240 的整数分钟。
   选择“不限时”后确认不应提交分钟数。AI 补充必须明确选择，导入题仅可选择“不纳入”。
5. 资料范围可明确选择“当前允许范围的全部可用资料”，也可打开“选择资料”指定文件。
   资料选择器保持同一主题，单次最多 100 份，未就绪资料不可新增勾选。切回配置后表单编辑应保留。
   若原对话已限制文件或章节，不应通过弹窗扩大范围；后端会复核。
6. 将同一内容同时填进“重点”和“排除内容”，确认后应在弹窗中提示冲突。修改后再次确认应保存配置并关闭弹窗。
7. 配置未确认时刷新页面，模型已识别的参数和待确认弹窗应恢复。尚未提交的本地表单修改不保证跨刷新保留。
   取消后刷新，不应再弹窗；重新发送出题请求可以重新配置。
8. 在手机宽度约 390 px 下检查：弹窗铺满屏幕，内容可纵向滚动，页脚按钮可操作，无横向溢出。
9. 确认成功显示“试卷配置已就绪，生成任务已排队”，刷新后继续显示任务进度。
   完成后打开试卷草稿，可查看答案、解析、得分点、轻量来源标记和原文摘录；来源链接进入资料预览。
   在“模拟测验”列表也能找回草稿。此阶段不提供编辑、确认、打印或正式作答入口。

## 自动验证

```powershell
uv run pytest -q
```

在 frontend 目录：

```powershell
npm run build
npm run test:e2e -- e2e/quiz-config.spec.ts e2e/chat.spec.ts
```

自动测试中的聊天模型使用确定性响应；实际模型的自然语言识别请按上面的步骤手动验证。
