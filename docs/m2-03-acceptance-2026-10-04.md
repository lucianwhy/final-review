# M2-03 验收记录（2026-10-04）

## 实现结果

新增课程“我的笔记”入口，区分待确认、已确认和已确认但有草稿修改的笔记。
列表展示类型、AI 生成/历史生成方式、更新时间与来源，五秒刷新并在窗口重新获得焦点时
读取更新。草稿生成即持久化，不依赖聊天是否仍打开。聊天旧草稿链接进入统一详情页。

按考点编辑标题、Markdown、引用标记与引用摘录；可添加/删除考点、选择当前课程资料
片段、添加/替换/移除引用。服务端保存新 revision，保留类型、阅读覆盖记录和逐条引用。
正文与逐条出处分别展示，来源可定位原文；历史引用继续保留资料版本，删除后展示快照。

确认前显示标题与考点变更数量，以及前后正文、来源和摘录。十分钟令牌绑定实际内容、
正式版本指针和最新版本。首次确认成为正式资产；再次确认替换当前正式版本，旧版只
改变状态并保留内容。旧版本链接仍可读取；未保存修改有离开/刷新提醒，确认需先保存。

保存和确认使用资产行锁及事务；过期编辑、过期预览、令牌重放、无效引用、跨用户及
跨课程来源被拒绝。新增 `007_note_review.sql` 回填最新版本入口与生成方式，并限制
同资产版本号唯一。编辑上限覆盖生成流程最多十二批的内容/引用合并，避免误套单次
模型输出的八条引用限制。

## 使用与边界

更新运行环境时，执行 `uv run python -m final_review.migrations`，重启后端与笔记 worker，
更新前端。迁移在隔离 PostgreSQL 验证了新库、旧库及重复执行；不修改正式版本内容。

本任务不新增模型生成路径，模型内容质量不由这些确定性测试证明。学生改写正文后
来源存在性与摘录真实性会重验，但不会自动进行模型语义复核。
无考点结构的旧通用笔记资产只支持查看；M2-02 生成的带考点笔记支持完整编辑。
富文本、协作、导出和笔记自动入检索库均不在本卡范围；正式版本导出仍归 M2-04。

接口与数据流说明见 [笔记编辑与确认](note-review.md)。
