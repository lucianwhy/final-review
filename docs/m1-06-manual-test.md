# M1-06 手动验收

## 准备

按 [README](../README.md#快速启动) 启动 PostgreSQL、迁移、API 和前端。普通聊天需要配置可用聊天模型。使用数据库登录模式准备账号 A、B；浏览器分别用普通窗口和无痕窗口登录。桌面窗口、手机尺寸浏览器各验一遍。

## 操作与预期

1. 账号 A 创建“数学”和“物理”两门课程。左上角“当前课程”打开课程/对话面板，选数学；“我的资料”中的课程也应变为数学。导航应显示“课程管理”。
2. 在数学的 AI 对话里发一条普通问答，记下回复。点“新对话”，空白页出现，面板历史数量不应立即增加；发送首问后才出现，标题应取首问开头。重复到数学有 7 个对话；在物理创建 2 个对话。
3. 打开数学面板：默认仅显示最近 5 条，按最近活动倒序；“查看更多”显示 7 条。打开最早一条，完整消息按发送顺序出现。继续发送一句明确依赖旧问答的追问，确认回复接得上；该对话应移到列表最上方，地址包含 `#chat/课程ID/会话ID`。
4. 去“课程管理”或“我的资料”，再点“AI 对话”：应回到刚才的数学会话。刷新页面，再直接复制该聊天地址到新标签页，仍应加载同一完整对话。点“新对话”后刷新，应保持空白，直到首次发送才产生记录。
5. 切到物理：面板只出现物理的 2 条；切回数学，应回到数学原会话。手机尺寸下，顶部“当前课程”也可完成这些操作。
6. 在当前旧对话页点击左上角对话标题，改为“期末重点”并保存；打开课程面板，历史名称应同步。再对该条历史右键，选“重命名对话”改为“考前冲刺”；刷新后聊天标题和历史名称都应保持新名称。课程选择列表应使用统一课程图标，点击整行可切课，不出现浏览器原生下拉框或圆圈对号。
7. 账号 B 打开账号 A 的聊天地址，以及直接请求 A 的 `/api/courses/{course_id}/conversations` 和 `/api/courses/{course_id}/conversations/{conversation_id}/messages`，均应无法读取，接口返回 404；尝试改名也应返回 404。账号 A 用物理课程 ID 请求数学会话消息或改名，也应返回 404。
8. 账号 A 删除当前课程后刷新，左上角应自动选另一门可用课程；恢复课程仍可在“课程管理”的回收期列表操作。

笔记生成的澄清和草稿卡片仍使用独立 Agent 会话，暂不出现在上述普通聊天历史；其合并验收属于 M2-05。
