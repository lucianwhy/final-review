# 数据结构期末复习笔记（示例）

## 一、线性表

### 定义
线性表是 n 个数据元素的有限序列，记作 (a1, a2, ..., an)。

### 顺序表 vs 链表
| 对比项 | 顺序表 | 链表 |
|--------|--------|------|
| 存储 | 连续内存 | 指针链接 |
| 随机访问 | O(1) | O(n) |
| 插入删除 | O(n) | O(1)（已知位置） |

### 易错点
- 顺序表插入要考虑扩容；链表插入别忘改指针。
- 头插法与尾插法建表结果顺序不同。

## 二、栈与队列

### 栈
后进先出（LIFO）。应用：括号匹配、表达式求值、函数调用。

### 队列
先进先出（FIFO）。循环队列避免假溢出：`(rear + 1) % MaxSize == front` 判满。

### 历年真题风格
判断：栈只能在栈顶操作。——正确。
简答：简述循环队列判空判满条件。

## 三、树与二叉树

### 二叉树性质
- 第 i 层最多 2^(i-1) 个结点。
- 高度为 h 的完全二叉树结点数在 [2^(h-1), 2^h - 1]。

### 遍历
先序、中序、后序、层序。已知先序+中序可唯一确定二叉树。

### 老师PPT重点
哈夫曼树：带权路径长度最短；哈夫曼编码前缀码、无歧义。

## 四、图

### 存储
邻接矩阵 O(V^2)；邻接表适合稀疏图。

### 最短路径
Dijkstra：非负权；Bellman-Ford：可负权但无负环。

## 五、排序与查找

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| 快排 | O(n log n) | O(n^2) | O(log n) | 否 |
| 归并 | O(n log n) | O(n log n) | O(n) | 是 |
| 堆排 | O(n log n) | O(n log n) | O(1) | 否 |

二分查找要求有序顺序表，时间 O(log n)。
